# Frontend-Experiment7: Dynamic Content Filtering (JavaScript Array Methods)

## Objective
This experiment demonstrates how to implement **dynamic content filtering** on a list of items (e.g., movies) using **JavaScript array methods**. Users can search through the list, and results update **in real-time** as they type.

## Features
- Displays a list of movies.
- Input field for live search/filter.
- Uses JavaScript's `filter()` and `includes()` methods.
- Minimal responsive design using CSS.

## Files
- `index.html` - Main HTML structure.
- `style.css` - Styles for layout and appearance.
- `script.js` - JavaScript logic for filtering the list.

## How to Run
1. Clone the repository or download the files.
2. Open `index.html` in a web browser.
3. Start typing in the search box to filter the movie list dynamically.
